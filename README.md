<h1>👋 Welcome! 👋</h1>
<h2>1. Introduction</h2>
This is a random project that I built in order to familiarise myself with the the Curses library. Obviously, this is not an entertaining game (it's barely even a game to begin with), but I had a blast coding this and I learned many concepts along the way. I'm sharing this as my first full-blown project 
<h2>2. How to set up</h2>
This project doesn't use any third-party libraries. However, if you don't use a Unix-based operating system (in other words, if you're a Windows user), you will have to download the Curses library manually. To do that, open the terminal and run the following command:
<br></br>

```bash
pip install windows-curses
```

<h1>🎮 The Game 🎮</h1>
<h2>1. How to play</h2>
The game is extremely simple:
<br></br>

1. Choose a character that fits your playing style!
2. Clear all 5 normal rooms by killing the enemies that come your way!
3. Claim items upon clearing a room that'll help you in your journey!
4. Beat the final boss!

You can have up to 3 different save files simultaneously.
